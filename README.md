## Installation

1. For RTX 40xx GPUs, follow the instructions: https://apollo.baidu.com/community/article/1212.
2. dev_start failure, follow the instructions: https://github.com/ApolloAuto/apollo/issues/15246, and use `-l` flag to `dev_start.sh`.
3. Build failure inside the container, change the number of jobs in `job_args` in `scripts/apollo_build.sh`.
