Introduction
============

CoCoMEGA is a search-based framework for generating metamorphic test cases in autonomous driving.
It combines evolutionary algorithms with driving simulations (using CARLA and external driving agents like the
InterFuser agent) to find scenario variations that violate specified Metamorphic Relations (MRs).

For more details about the design, please refer to our paper titled *Using Cooperative Co-evolutionary Search to
Generate Metamorphic Test Cases for Autonomous Driving Systems* by Hossein Yousefizadeh, Shenghui Gu, Lionel C. Briand,
and Ali Nasr.
